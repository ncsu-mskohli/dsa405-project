# dsa405-project
This is a project that intends to help compare the used car market of Raleigh, NC with nationwide statistics.<br>
Details on how raw data was gathered are recorded in [SOURCES.md](/data/raw/SOURCES.md). All raw data for this project will be uploaded to this repository and never be overwritten, following the "Raw data preserved unmodified" principle. <br><br>
**10/7/2026:** The latest stage of our project was cleaning data from a scrape of a local dealership's inventory. The notebook for this can be found [here](notebooks/DSA405_002_FA26_P2_mskohli.ipynb). Going to that page and clicking on the button that says "Open in Colab" will open the notebook in the Google Colab environment. When you click "Run All," the raw data will be cleaned and a new dataset will be generated and saved into a local temporary directory, "files."
**Note:** The [clean data](/data/clean) and [notebooks](/data/notebooks) are not static! Github saves a copy of them each time they're updated, so you can always go back and find something, but the version that first opens up for you may not stay consistent as they may be updated to fit the needs of the project.
